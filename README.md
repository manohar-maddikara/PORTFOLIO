# 🚀 Manohar Reddy Maddikara | AI & ML Engineer Portfolio

An interactive, modern ChatGPT-style personal portfolio for **Manohar Reddy Maddikara**, showcasing machine learning projects, engineering journey, skills, and certifications with dynamic WebGL fluid physics and dual chat/overview modes.

---

## ✨ Features

- 💬 **Interactive Chat Interface**: ChatGPT-style conversational assistant ("Manohar GPT") answering queries about projects, background, skills, and experience.
- 🌊 **WebGL Fluid Simulation**: Interactive background physics responsive to mouse and touch interactions.
- 🎛️ **Dual Experience**: Switch seamlessly between interactive conversation mode and structured overview.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile displays.
- ⚡ **Zero Heavy Framework Overheads**: Built with high-performance Vanilla HTML5, CSS3, and JavaScript.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Custom Design System & Glassmorphism), Vanilla JavaScript (ES6+)
- **Visuals & Graphics**: WebGL Fluid Dynamics (`fluid.js`), Lucide Icons
- **Deployment**: GitHub Pages / Static Web Hosting

## 💻 Local Development

To run this portfolio locally:

1. Clone or download the repository:
   ```bash
   git clone https://github.com/manohar-maddikara/portfolio.git
   cd portfolio
   ```

2. Open `index.html` directly in your browser or run a local development server (e.g., VS Code Live Server or `npx serve`).
